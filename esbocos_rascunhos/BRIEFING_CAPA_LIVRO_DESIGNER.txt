3. PALETA DE CORES
════════════════════════════════════════════════════════════════════════════════

COR PRIMÁRIA:
  • Verde Escuro: #1a472a (RGB: 26, 71, 42)
  • Uso: Títulos, elementos principais, background
  • Razão: Confiança, crescimento, investimento

COR SECUNDÁRIA:
  • Ouro: #d4af37 (RGB: 212, 175, 55)
  • Uso: Acentos, separadores, "Bíblia", destaque
  • Razão: Luxo, valor, objetivo (conseguir ouro em forma de desconto)

COR TERCIÁRIA:
  • Cinza Escuro: #2b2b2b (RGB: 43, 43, 43)
  • Uso: Texto corpo, subtítulos
  • Razão: Legibilidade, seriedade

FUNDO:
  • Opção A: Branco puro (#ffffff) com textura sutil
  • Opção B: Verde escuro (#1a472a) com tipografia clara
  • RECOMENDAÇÃO: Branco com ouro para Frente; Verde para Verso/Contracapa

CORES A EVITAR:
  ✗ Vermelho (associa risco, queda)
  ✗ Rosa/roxo (muito soft para tema)
  ✗ Preto puro (muito pesado, sem nuance)

5. ELEMENTOS GRÁFICOS
════════════════════════════════════════════════════════════════════════════════

FRENTE (Recomendações):

Opção A — Minimalista (Preferida):
  • Fundo branco com textura subtle (linen 5%)
  • Título + Subtítulo centrado, tamanho grande
  • Elemento geométrico sutil: linha ouro horizontal separando espaços
  • Sem fotografia, sem complexidade
  • Profissional, intemporal, fácil de reconhecer à distância

Opção B — Com Elemento Visual:
  • Incorporar ícone/ilustração de:
    - Chave + imóvel (símbolo de propriedade)
    - Gráfico ascendente (lucro)
    - Leilão (martelo estilizado)
  • Ícone em ouro sobre fundo verde (ou vice-versa)
  • Tamanho moderado (não domina a capa)

Opção C — Com Fotografia (Menos Recomendado):
  • Se usar foto: imóvel premium, bem iluminado, aspiracional
  • Filtro verde/ouro overlay (40-50% opacidade) para manter a paleta
  • Foto NUNCA deve ser o destaque principal
  • Prefira ilustração ou conceitual a "foto genérica de imóvel"

8. PROCESSO DE APROVAÇÃO
════════════════════════════════════════════════════════════════════════════════

ETAPA 1: Conceito (2-3 dias)
  Designer apresenta:
  □ 2-3 conceitos visuais (sketch/rascunho)
  □ Paleta de cores aplicada
  □ Tipografia escolhida
  
  Você escolhe direção (A, B, ou C)

ETAPA 2: Design Completo (3-4 dias)
  Designer entrega:
  □ Capa frente/verso/lombada em alta resolução
  □ PSD/AI (working files)
  □ Mockup de como ficará impresso
  
  Você revisa e solicita ajustes

ETAPA 3: Ajustes Finais (2 dias)
  Designer corrige:
  □ Alinhamento de texto
  □ Cores (CMYK final)
  □ Resolução e resolução (300 DPI)
  
  Aprovação final

ETAPA 4: Entrega Final (1 dia)
  Arquivos entregues:
  ✓ PDF/X-1a (pronto para gráfica)
  ✓ PSD (para futuras edições)
  ✓ Mockup final
  ✓ Instruções para gráfica (se necessário)
