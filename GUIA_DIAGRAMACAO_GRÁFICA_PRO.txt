4. CAMINHO 2: FAZER VOCÊ MESMO (DIY) EM WORD
════════════════════════════════════════════════════════════════════════════════

SE VOCÊ QUER FAZER:

Tempo necessário: 40-60 horas (espalhe em 3-4 semanas)
Custo: R$ 50-200 (Microsoft Word subscription)
Complexidade: Média (requer paciência)
Resultado: 90% da qualidade profissional

PASSO 1: PREPARAR ARQUIVO WORD BASE

┌─────────────────────────────────────────────────────────┐
│ 1. Abra seu livro (A_BIBLIA_DO_LEILAO_IMOBILIARIO_      │
│    COMPLETO.txt) no Word                                │
│                                                          │
│ 2. Remova toda formatação manual:                        │
│    • Select All (Ctrl+A)                                │
│    • Paste Special > Unformatted Text                    │
│    (Editar > Colar Especial > Texto Sem Formatação)     │
│                                                          │
│ 3. Resultado: Arquivo limpo, só texto                   │
│                                                          │
│ 4. Salve como: LIVRO_BASE.docx                          │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 2: CONFIGURAR PÁGINA

┌─────────────────────────────────────────────────────────┐
│ Em Word → Design/Layout:                                │
│                                                          │
│ Tamanho:                                                │
│ ├─ Clique "Tamanho" > "Mais Tamanhos de Página"        │
│ ├─ Largura: 170mm                                       │
│ ├─ Altura: 240mm                                        │
│ ├─ OK                                                   │
│                                                          │
│ Margens:                                                │
│ ├─ Clique "Margens" > "Personalizado"                  │
│ ├─ Superior: 20mm                                       │
│ ├─ Inferior: 20mm                                       │
│ ├─ Esquerda (verso): 18mm                               │
│ ├─ Direita (verso): 20mm                                │
│ ├─ Diferentes em pares para frente/verso: SIM           │
│ ├─ OK                                                   │
│                                                          │
│ Espaçamento de parágrafo:                               │
│ ├─ Antes: 0pt                                           │
│ ├─ Depois: 12pt                                         │
│ ├─ Espaçamento de linhas: Exatamente 18pt               │
│    (= 1.5 linhas em 12pt)                               │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 3: CRIAR ESTILOS DE PARÁGRAFO

┌─────────────────────────────────────────────────────────┐
│ Em Word → Home > Estilos > Nova Lista > Novo Estilo:   │
│                                                          │
│ ESTILO 1: "Corpo" (Body)                                │
│ ├─ Fonte: Crimson Text (ou Georgia)                     │
│ ├─ Tamanho: 12pt                                        │
│ ├─ Cor: #2b2b2b                                         │
│ ├─ Line spacing: 1.5                                    │
│ ├─ Parágrafo: First-line indent 12pt                    │
│ ├─ Salve como Normal                                    │
│                                                          │
│ ESTILO 2: "Títulodekapi" (Título Capítulo)             │
│ ├─ Fonte: Montserrat Bold                               │
│ ├─ Tamanho: 28pt                                        │
│ ├─ Cor: #1a472a                                         │
│ ├─ Alignment: Centrado                                  │
│ ├─ Spacing: 40pt antes, 20pt depois                     │
│                                                          │
│ ESTILO 3: "Subtitulo" (Seção)                           │
│ ├─ Fonte: Lato Bold                                     │
│ ├─ Tamanho: 12pt                                        │
│ ├─ Cor: #1a472a                                         │
│ ├─ Spacing: 15pt antes, 10pt depois                     │
│                                                          │
│ ESTILO 4: "Box" (Destaques)                             │
│ ├─ Fonte: Crimson Text 11pt                             │
│ ├─ Cor: #2b2b2b                                         │
│ ├─ Borda: Box verde (#1a472a)                           │
│ ├─ Preenchimento: Cinza #f9f9f9                         │
│ ├─ Espaço interno: 12pt                                 │
│                                                          │
│ Repita para: Tabelas, Listas, Glossário, Citações      │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 4: APLICAR ESTILOS AO TEXTO

┌─────────────────────────────────────────────────────────┐
│ Para cada capítulo:                                      │
│                                                          │
│ 1. Selecione o título do capítulo                       │
│ 2. Clique no estilo "Titulodekapi"                      │
│ 3. Selecione as seções                                  │
│ 4. Clique no estilo "Subtitulo"                         │
│ 5. Selecione o corpo do texto                           │
│ 6. Clique no estilo "Corpo"                             │
│ 7. Insira quebra de página entre capítulos:             │
│    Ctrl+Return                                          │
│                                                          │
│ Tempo: ~2 minutos por capítulo × 27 caps = 54 min      │
│                                                          │
│ Para tabelas:                                           │
│ 1. Insira tabela (Insert > Table)                       │
│ 2. Formate com estilo "Tabela"                          │
│ 3. Linhas alternadas: cinza/branco                      │
│                                                          │
│ Para boxes:                                             │
│ 1. Insira caixa de texto                                │
│ 2. Aplique estilo "Box"                                 │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 5: ADICIONAR CABEÇALHO E RODAPÉ

┌─────────────────────────────────────────────────────────┐
│ Em Word → Insert > Header:                              │
│                                                          │
│ Cabeçalho (páginas pares/verso):                        │
│ "Página XX | Nome do Capítulo"                          │
│ Fonte: Lato 11pt, cor #1a472a                           │
│ Alinhado à direita                                      │
│                                                          │
│ Cabeçalho (páginas ímpares/recto):                      │
│ "Capítulo X: Título | Página XX"                        │
│ Fonte: Lato 11pt, cor #1a472a                           │
│ Alinhado à direita                                      │
│                                                          │
│ Rodapé (ambas):                                         │
│ Linha separadora (#d4af37, 1pt)                         │
│ Número de página (Lato 11pt bold, #1a472a)             │
│                                                          │
│ Nota: Use "Different odd and even" para fazer           │
│ verso/recto diferentes                                  │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 6: INSERIR TABELAS

┌─────────────────────────────────────────────────────────┐
│ Para cada tabela do livro:                              │
│                                                          │
│ 1. Insert > Table > [número de colunas/linhas]         │
│ 2. Copie os dados da sua tabela                         │
│ 3. Cole na tabela Word                                  │
│ 4. Formate:                                             │
│    • Header row: Verde #1a472a, texto branco            │
│    • Linhas pares: Cinza #f5f5f5                        │
│    • Linhas ímpares: Branco                             │
│    • Bordas: 1pt cinza                                  │
│    • Fonte: Minion 10pt                                 │
│ 5. Insira caption (título da tabela acima)              │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 7: NUMERAR PÁGINAS CORRETAMENTE

┌─────────────────────────────────────────────────────────┐
│ Front Matter (páginas i-xii — algarismos romanos):      │
│ • Rosto: sem número                                     │
│ • Verso: sem número                                     │
│ • Créditos: ii                                          │
│ • Sumário: iii-iv                                       │
│ • Prefácio: v-vii                                       │
│                                                          │
│ Corpo (páginas 1-153 — algarismos arábicos):            │
│ • Capítulo 1 começa página 1                            │
│ • Continue sequencial                                    │
│                                                          │
│ Back Matter (continua sequencial):                      │
│ • Apêndices: página 165+                                │
│                                                          │
│ Para fazer em Word:                                     │
│ 1. Insert > Page Numbers                                │
│ 2. Format > Restart numbering (para mudar de i→1)      │
│ 3. Use section breaks para diferentes estilos           │
│                                                          │
└─────────────────────────────────────────────────────────┘

PASSO 8: EXPORTAR PARA PDF

┌─────────────────────────────────────────────────────────┐
│ File > Export As > Create PDF:                          │
│                                                          │
│ Configurações:                                          │
│ • Tamanho do papel: A5 (170x240mm)                      │
│ • Qualidade: "Standard" (ou máxima se disponível)       │
│ • Margens: Nenhuma (já está no documento)               │
│ • Cores: RGB ou CMYK (para impressão: CMYK)             │
│ • Resolução: 300 DPI                                    │
│ • Compressão: Média                                     │
│ • Salve como: LIVRO_FINAL.pdf                           │
│                                                          │
│ IMPORTANTE:                                             │
│ Se tiver Adobe Acrobat Pro, salve como:                │
│ File > Save As > PDF/X-1a (para máxima compatibilidade)│
│ Isto garante que a gráfica consegue usar               │
│ exatamente como você preparou                           │
│                                                          │
└─────────────────────────────────────────────────────────┘
