OBJETIVO
═══════════════════════════════════════════════════════════════════════════════

Converter o arquivo de texto em um documento Word (.docx) profissional e 
pronto para publicação, mantendo a integridade do conteúdo e maximizando 
a apresentação visual.

Tempo estimado: 2-3 horas
Dificuldade: Média
Ferramentas necessárias: Microsoft Word 2016 ou superior


════════════════════════════════════════════════════════════════════════════════
PARTE 1: PREPARAÇÃO INICIAL
════════════════════════════════════════════════════════════════════════════════

PASSO 1.1: Criar novo documento Word
─────────────────────────────────────────────────────────────────────────────
1. Abra Microsoft Word
2. Crie um novo documento em branco (Ctrl + N)
3. Salve como: "Biblia_Leilao_Imobiliario_FINAL.docx"
4. Local: Desktop ou Dropbox para backup


PASSO 1.2: Configurar página
─────────────────────────────────────────────────────────────────────────────
1. Vá para: Arquivo > Opções > Avançadas
2. Scroll até "Mostrar"
3. Marque: "Mostrar marcas de parágrafo"

4. Vá para: Layout da Página > Margens
   • Superior: 2,5 cm
   • Inferior: 2,5 cm
   • Esquerda: 3,0 cm
   • Direita: 2,0 cm

5. Vá para: Página > Tamanho
   • Tamanho do papel: A4 (210 x 297 mm)
   • Orientação: Retrato

6. Vá para: Layout > Quebras > Quebra de Página
   (Para usar depois entre partes)


PASSO 1.3: Configurar fontes e espaçamento
─────────────────────────────────────────────────────────────────────────────
1. Selecione tudo (Ctrl + A)

2. Vá para: Página Inicial > Fonte
   • Fonte: Calibri (ou Times New Roman)
   • Tamanho: 12 pt
   • Cor: Preto automático
   • Efeitos: Normal

3. Vá para: Página Inicial > Parágrafo
   • Espaçamento antes: 0 pt
   • Espaçamento depois: 6 pt
   • Espaçamento entre linhas: 1,5 linhas
   • Alinhamento: Esquerda

PASSO 2.2: Aplicar estilos ao documento
─────────────────────────────────────────────────────────────────────────────

1. Importe o conteúdo de texto
2. Para cada TÍTULO DE PARTE (════════...):
   • Selecione a linha
   • Clique no estilo "Titulo_Parte"
   
3. Para cada CAPÍTULO (Capítulo X: ...):
   • Selecione a linha
   • Clique no estilo "Titulo_Capitulo"
   • Insira Quebra de Página ANTES (Ctrl + Enter)

4. Para cada SEÇÃO (1.1, 1.2, etc.):
   • Selecione a linha
   • Clique no estilo "Titulo_Secao"

5. Para corpo de texto:
   • Deixe no estilo "Normal"
   • Mude alinhamento para Justificado

PARTE 3: TRATAMENTO DE TABELAS
════════════════════════════════════════════════════════════════════════════════

PASSO 3.1: Inserir e formatar tabelas
─────────────────────────────────────────────────────────────────────────────

O documento contém 28 tabelas. Para cada tabela:

1. Selecione o texto da tabela ASCII (╔═══╦═══╗ formato)
2. Vá para: Inserir > Tabela
3. Escolha: Converter > Texto em tabela
   • Separador: Use espaços ou tabs
   • Número de linhas: Conforme a tabela
   • Número de colunas: Conforme a tabela

4. Após criada a tabela:
   • Selecione a primeira linha (cabeçalho)
   • Vá para: Ferramentas de Tabela > Design
   • Aplique estilo: "Tabela de Tema 1" ou "Tabela de Tema 2"
   • Marque: "Linha de Cabeçalho"
   
5. Formate:
   • Fonte da tabela: Calibri 11pt
   • Alinhamento: Células central
   • Largura: Auto
   • Bordas: Padrão (preto 1pt)

6. Após a tabela, insira um parágrafo em branco

─────────────────────────────────────────────────────────────────────────────

PARTE 5: SUMÁRIO E ÍNDICE AUTOMÁTICO
════════════════════════════════════════════════════════════════════════════════

PASSO 5.1: Gerar Sumário Automático
─────────────────────────────────────────────────────────────────────────────

IMPORTANTE: Só funciona se usou estilos (Título 1, Título 2, etc.)

1. Insira nova página para o Sumário (após Prefácio)
2. Título: SUMÁRIO (Estilo Titulo_Parte, tamanho reduzido)
3. Vá para: Referências > Sumário
4. Escolha: Sumário Automático (estilo moderno)
5. Configure:
   • Mostrar: Níveis 1 e 2 (capítulos e seções)
   • Hiperlinks: Marcada (para PDF interativo)

6. Word gerará automaticamente lista de capítulos


PASSO 5.2: Gerar Índice Remissivo
─────────────────────────────────────────────────────────────────────────────

1. Vá para o final do documento
2. Insira nova página
3. Título: ÍNDICE REMISSIVO
4. Use a lista de termos já presente no documento
5. Formate como lista em 2 colunas:
   • Vá para: Layout > Colunas > 2 colunas

PARTE 11: EXPORTAÇÃO E FINALIZAÇÃO
════════════════════════════════════════════════════════════════════════════════

PASSO 11.1: Salvar como PDF (para publicação)
─────────────────────────────────────────────────────────────────────────────

1. Vá para: Arquivo > Exportar como PDF
2. Configure:
   • Qualidade: Padrão (não Alto - arquivo menor)
   • Intervalo: Todas as páginas
   • Opções:
     ✓ Criar marcadores
     ✓ Propriedades do documento
     ✓ Hiperlinks

3. Clique em: Opções
   • Compatibilidade: PDF/A (para arquivo)

4. Salve como:
   Biblia_Leilao_Imobiliario_2026_FINAL.pdf


PASSO 11.2: Preparar para Amazon KDP (E-BOOK)
─────────────────────────────────────────────────────────────────────────────

1. Salve como: DOCX (mantém formatação)
   Arquivo > Salvar Como > Formato: Word (.docx)

2. Envie para Amazon KDP:
   • Vá para: kdp.amazon.com
   • Crie novo projeto e-book
   • Upload do arquivo DOCX

3. Amazon converterá para MOBI automaticamente


PASSO 11.3: Preparar para Publicação Impressa
─────────────────────────────────────────────────────────────────────────────

1. Para Amazon Print on Demand:
   • Converta DOCX para PDF (alta resolução)
   • Verifique: Tamanho da fonte, linhas por página
   • Envie para KDP Print

2. Para Impressora Local:
   • Arquivo > Imprimir
   • Impressora: Selecione PDF de alta resolução
   • Papel: A4
   • Qualidade de impressão: Máxima

PARTE 13: SOLUÇÃO DE PROBLEMAS COMUNS
════════════════════════════════════════════════════════════════════════════════

PROBLEMA: Espaçamento desigual entre linhas
SOLUÇÃO:
  1. Selecione parágrafo
  2. Parágrafo > Espaçamento de linha: 1,5 linhas
  3. Se persistir: Remova espaçamento antes/depois

PROBLEMA: Tabelas saem da página
SOLUÇÃO:
  1. Redimensione a tabela (arraste borda)
  2. Ou: Redimensione colunas individualmente
  3. Ou: Mude orientação para Paisagem apenas nesta página

PROBLEMA: Imagens aparecem desfocadas
SOLUÇÃO:
  1. Clique na imagem > Ferramentas de Imagem
  2. Compressão de Imagem > Compactar Imagens
  3. Mantém qualidade mas reduz tamanho

PROBLEMA: Hyperlinks não funcionam no PDF
SOLUÇÃO:
  1. Converta DOCX > PDF via Adobe (melhor) ou Word
  2. Verifique: Todos os estilos de título foram usados
  3. Recrie sumário antes de exportar
